# CLAUDE.md

## Проект
Blockparty — социальный 3D открытый мир в стиле low-poly для Steam (Windows).
Полное ТЗ: docs/SPEC.md (версия 2.2). Прежнее 2D-ТЗ: docs/archive/SPEC_2d.md — только для справки.
Текущий этап и отчёты: docs/STATUS.md.
Стек: Godot 4.7.2 (Forward+) + GDScript (строгая типизация) + GodotSteam 4.22.1. Своего бэкенда нет.

## Как работать
- Работай строго по этапам из раздела 17 SPEC.md (П0–П4, П4.5, П5–П8). Текущий этап — в docs/STATUS.md.
- В начале этапа составь план файлов и изменений и покажи его, прежде чем писать код.
- В конце этапа: прогони тесты GUT, обнови docs/STATUS.md (что сделано, как проверить
  вручную, что отложено, известные проблемы) и остановись, дождись подтверждения.
- Один этап — одна ветка git (p0, p1, ...), осмысленные коммиты.
- Не реализуй ничего из раздела 19 SPEC.md. Если без этого нельзя — спроси.
- Не добавляй плагины и библиотеки без согласования (движок и аддоны не трогай).
- Ресурсы (3D-модели, текстуры, HDRI, звуки, шрифты) — только CC0 и только с сайтов
  из раздела «Скачивание ресурсов» ниже. Рельеф острова и персонаж — процедурные.
- Если требование неоднозначно или противоречиво — спроси, не додумывай.

## Правила кода
- GDScript со статическими типами везде. snake_case для файлов и переменных,
  class_name в PascalCase. 1 единица = 1 метр.
- Числа геймплея — в gameplay/balance.tres, сетевые константы — в net/protocol.gd.
- Обращения к GodotSteam — только внутри autoload/steam_service.gd.
- Режим разработки через ENet (--dev-host / --dev-join) должен работать всегда.
- Весь текст UI — через tr() и i18n/strings.csv (ru, en).
- Генерация острова и движение мобов детерминированы: только RandomNumberGenerator
  и FastNoiseLite с фиксированным seed, никаких randi()/randf() в этих местах.
- Визуал отделён от логики: модели — дочерние сцены, которые можно заменить.
- Сцены не ссылаются друг на друга напрямую: сигналы и EventBus.
- Имена функций и сигналов GodotSteam сверяй с документацией 4.22.1, не угадывай.

## Этапы с персонажами: обязательная проверка анимаций

Любой этап, меняющий персонажей, их модели, скелеты, риг или анимации,
сдаётся с дополнительными проверками:

1. Тест поз костей: создать персонажа, включить ходьбу, прокрутить ≥0.5 с —
   позы ключевых костей (бедро, колено, плечо) должны заметно отличаться от
   позы покоя, в числах, с порогом.
2. Тест резолва: каждая дорожка каждого используемого клипа находит свою
   кость на риге.
3. Ключ --selftest-anim: та же проверка в запущенной игре — вывод PASS/FAIL,
   код возврата != 0 при FAIL. Прогон на экспортированной Linux-сборке с теми
   же настройками экспорта (фильтры ресурсов, включённые файлы), что и у
   Windows-пресета.
4. Зелёные тесты, файлы, лицензии и сборка без пунктов 1–3 не считаются
   доказательством работающих анимаций.
5. Если неясно, относится ли этап к персонажам, — считать относящимся.
6. Исправления анимаций проходят по этим же правилам.
7. Если хотя бы одна из проверок 1–3 не PASS, этап не сдаётся и не сливается,
   даже если всё остальное зелёное.

## Визуальные материалы и приёмка

1. Скриншоты, GIF, видео, склейки «было — стало» и съёмку времён суток НЕ делать — ни для отчётов, ни для приёмки, ни «для себя». Визуал владелец проверяет сам в Windows-сборке.
2. Замеры FPS на сервере не делать: сервер рендерит программно (llvmpipe), цифры бессмысленны.
3. Приёмка этапа: GUT зелёные, --selftest-anim PASS, STATUS.md, коммит/push, Windows-сборка — и всё. Время прогона тратить на код, а не на материалы.
4. После каждого этапа — стоп и ждать «принято» владельца по сборке exe. Режим «без остановок» отменён.
5. Отчёт владельцу — коротко: что сделано, что не получилось, известные дефекты, где сборка. Без обещаний «финальный».

## Скачивание ресурсов
### Разрешено без вопросов
Скачивать файлы ресурсов (3D-модели, текстуры, HDRI-небо, звуки, шрифты) только
с этих сайтов и только с лицензией CC0:

| Сайт | Что брать |
| --- | --- |
| quaternius.com | low-poly модели: деревья, камни, трава, руины, природа |
| kenney.nl | low-poly модели, звуки, элементы интерфейса |
| polyhaven.com | текстуры, HDRI-небо |
| ambientcg.com | текстуры |

Допустимые форматы: `.glb`, `.gltf`, `.obj`, `.png`, `.jpg`, `.webp`, `.hdr`,
`.exr`, `.ogg`, `.wav`, `.ttf`, `.otf`, а также `.zip` с этими файлами внутри.

### Обязательно при каждом скачивании
- Класть файлы в `assets/third_party/<сайт>/<набор>/`.
- Записывать в `assets/third_party/LICENSES.md`: имя набора, автор, прямая ссылка
  на страницу, лицензия (CC0), дата скачивания.
- Брать только те файлы, которые реально используются в игре. Неиспользуемое
  из архивов удалять, архивы в git не класть.
- Общий размер `assets/third_party/` — не больше 300 МБ. Если файл больше 10 МБ
  и Git LFS в репозитории не настроен — остановиться и спросить.

### По-прежнему запрещено без согласия владельца (остановись и позови)
- Устанавливать программы и пакеты: `apt`, `pip`, `npm`, плагины Godot, любые
  исполняемые файлы и скрипты из интернета.
- Скачивать с других сайтов или файлы с лицензией не CC0.
- Платные сервисы, сервисы с регистрацией или API-ключом, генерация через ИИ-сервисы.

## Безопасность
- Никаких секретов в репозитории (URL webhook, ключи). Конфиг — user://config.cfg.
- Ассеты только с известной лицензией, каждый — в assets/CREDITS.md
  (сторонние CC0 — в assets/third_party/LICENSES.md).

## Окружение
- Разработка идёт на Linux-сервере без экрана. Steam-клиента и микрофона нет.
- Godot, GodotSteam, GUT и шаблоны экспорта уже установлены. Не скачивай и не
  обновляй движок и аддоны; если чего-то не хватает — остановись и сообщи.
- Проверки headless: godot --headless, тесты GUT, боты через --bot.
  Если доступен xvfb-run — можно снимать скриншоты в docs/screenshots/ для самопроверки.
- Steam-функции (П4, П6) здесь проверить нельзя: код пиши, а в отчёте перечисли,
  что проверить вручную на двух ПК со Steam.
- Визуальную часть и «приятно ли играть» проверяет человек: в отчёте напиши,
  куда сходить (--dev-spawn=ZONE) и на что посмотреть.
- После каждого этапа — git commit и push.

- tools/run_local.sh — хост и N клиентов (ENet), на сервере в режиме --headless.
- Тесты: godot --headless -s addons/gut/gut_cmdln.gd
