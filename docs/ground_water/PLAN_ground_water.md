## D. ЗЕМЛЯ

### D.1. Слои — те же веса ForestGround, новые карты (SPEC 2.1)

Карты весов `ForestGround` и их генерация **не меняются** (r камень, g влага,
b мох, a тропа/гравий). Меняется то, чем шейдер красит каждый вес:

| Вес/слот | Было | Станет (набор) | Карты |
| --- | --- | --- | --- |
| база «подстилка» (s ≥ 0.5) | forest_ground_05 diffuse | **forest_ground_05**, полный PBR | diff 2K + nor_gl 2K + ORM 2K |
| база «трава» (s < 0.5, луга) | Grass001 diffuse | **leafy_grass** (polyhaven) | diff 1K + nor_gl 1K + ORM 1K |
| w.r — скала (уклон) | плоский цвет rock_color | **rock_face_03** (polyhaven) | diff 2K + nor_gl 2K + ORM 2K |
| w.g — грязь (низины) | плоский цвет wet_color | **mud_forest** (polyhaven) | diff 1K + nor_gl 1K + ORM 1K |
| w.b — мох (шум) | плоский цвет moss_color | **Moss001** (ambientcg; Color 1K уже в проекте) | + nor_gl 1K + ORM 1K |
| w.a — гравий (тропа/Площадь) | плоский цвет path_color | **rocky_trail** (polyhaven) | diff 2K + nor_gl 2K + ORM 2K |

Текстура-вариация тона подстилки (опция, по желанию владельца): forest_ground_04 —
второй набор подстилки, микс с 05 крупным шумом 50–100 м (+11 МБ). Без него вариация
тона делается шумовым тинтом в шейдере.

Плоские цвета оверлеев (wet/moss/rock/path_color) остаются в материале как тинты
поверх новых карт — яркость и тон каждого слоя владелец подбирает на живой сборке.

### D.2. ORM-упаковка (SPEC 1.2)

- Новая текстура на слой: **ORM = R: AO, G: Roughness, B: Height(displacement)** —
  не больше 3 текстур на слой (diffuse + nor_gl + ORM).
- Скрипт `tools/make_orm_textures.gd` (headless, запускается вручную при подготовке
  ассетов): читает AO/Roughness/Displacement исходники из `~/blockparty/library/`,
  собирает ORM, кладёт результат в `assets/third_party/<сайт>/<набор>/`.
  Исходники (ao/rough/disp по отдельности) в git **не попадают** — только ORM.
- Импорт: мип-мапы, анизотропия 4×, VRAM-сжатие (в .import); SIMPLE уже сэмплит
  из мипа 1K (SIMPLE_MIPMAP_BIAS из П11-фундамента).

### D.3. `assets/shaders/forest_ground.gdshader` — переделка (SPEC 2.2–2.7)

Сохраняются: симплекс-шум пятнистости, трипланар базы и нормалей по мировой
нормали рельефа (relief_normal), карта тона border_map и краевой toon-переход,
wrap-Ламберт + toon light(). Новое:

1. **Height-blend оверлеев (2.2):** побеждает слой с выше картой высоты: для каждого
   слоя h_i' = ORM.b_i + w_i; веса перенормируются по h_i' с мягкостью
   `BLEND_SOFTNESS` (константа). Грязь утекает между камнями, мох лезет поверх.
2. **Полный PBR (2.3):** ROUGHNESS — взвешенная сумма ORM.g слоёв; AO — из ORM.r
   через встроенный `AO` + `AO_LIGHT_AFFECT ≈ 0.5`.
3. **Против повторов (2.4):** поворот UV на 0/90° и зеркало по ячейке value-noise
   (масштаб ≈ 30 м) для основного слоя; крупная вариация тона — симплекс 50–100 м
   (`TONE_VAR_SCALE`), амплитуда ~10%.
4. **Мокрая земля и лужи (2.5):** по весу w.g без изменения карт: albedo темнеет
   (`WET_DARKEN ≈ 0.65`), roughness падает (×0.55). Лужа — при w.g ≥ `PUDDLE_START`
   (то же значение 0.9, что ForestGround.PUDDLE_WET — лужи совпадут со всплесками
   FootFx): roughness → 0.05, край плавный smoothstep(0.9, 1.0). Отражают небо
   спекуляром и (на ULTRA) SSR из bu-gfx.
5. **Параллакс (2.6):** дешёвый параллакс по высоте ORM.b со смещением UV от
   view-направления, включён только при `tier >= HIGH`, затухание 15→25 м.
6. **Уровни качества:** uniform `quality` (SIMPLE/NORMAL/HIGH/ULTRA) выставляет
   `ForestGround.make_material` из `GraphicsQuality.tier_from_settings()`.
   SIMPLE: без AO-карт, без луж, без параллакса (по цене текущего), ORM.g →
   константная roughness; слой травы не сэмплится (луга красит карта тона).
7. **Тинты BU (2.7):** приглушённые холодные — константами в `forest_terrain.gd`
   (TINT_LITTER/GRASS/ROCK/MUD/MOSS/GRAVEL, WET_DARKEN, PUDDLE_*), «подбирает
   владелец» в сборке.

Оценка цены: ~40–50 texture fetch на фрагмент (слои почти не пересекаются по
весам — реальный вклад обычно 2–3 слоя). Forward+ для Steam-десктопов; если
владельцу покажется дорого — упрощение: ORM только верхняя плоскость (не
трипланар) уже так, albedo/nor оставить трипланар как сейчас.

## F. ВОДА (`water_area.gd`; SPEC 4.1–4.7)

Аддон Boujie Water остаётся; **шейдер аддона больше не правится вообще** — вместо
этого две копии в проекте (SPEC 4.4: «копия в проекте, а не два дефайна в аддоне»):

- `assets/shaders/water_plain.gdshader` — копия текущего шейдера аддона с уже
  сделанными правками (REFRACTION off, фильтры) **минус ALBEDO_WAVE и без сэмпла
  `texture_albedo`** (SPEC 4.2 — «нарисованная» текстура выключена в ноль;
  ocean_albedo_1.png не используется). Для SIMPLE/NORMAL.
- `assets/shaders/water_refraction.gdshader` — то же + `#define REFRACTION`
  (и REFRACTION_SCALING уже есть). Для HIGH/ULTRA (SPEC 4.4).

`water_area.gd`:

1. **Палитра BU (4.1):** константы вместо PAL.water/PAL.water_deep (бирюзу не
   использовать): озеро — глубина почти чёрная с зелёно-бурым (торфяная), мелководье
   прозрачное; море — холодная стальная серо-синяя. Значения-стартовые в плане,
   финал «подбирает владелец»: `LAKE_DEEP ≈ Color(0.016, 0.035, 0.028)`,
   `LAKE_SHALLOW ≈ Color(0.10, 0.14, 0.10, 0.30)`, `SEA_DEEP ≈ Color(0.02, 0.03, 0.045)`,
   `SEA_SHALLOW ≈ Color(0.09, 0.12, 0.14, 0.35)`. beers_law выше (торфяная мгла).
2. **ALBEDO_WAVE ≈ 0 (4.2):** решено копией шейдера без текстуры (чище, чем вес).
3. **Отражения (4.3):** roughness 0.03 (диапазон 0.02–0.05), френель уже в шейдере
   (дефайн FRESNEL, степень 3) — в упор прозрачная вода, под углом зеркало.
   Двойных отражений с SSR нет: френель шейдера — микс цвета неба, не screen-space;
   проверяется владельцем на ULTRA после bu-gfx.
4. **Преломление (4.4):** выбор шейдера по `GraphicsQuality.tier_from_settings()`
   в `_surface_material` (вода строится один раз при входе в мир — смена качества
   применяется при следующем входе, как у остального мира).
5. **Волны (4.5):** озеро — почти гладь: амплитуды вниз, короткая рябь двух
   масштабов (второй детальный ~5 м); море — умеренные Герстнеры (текущие
   амплитуды чуть вниз, без «пластилина»). Дождя нет — кольца от капель не делаем.
6. **Пена (4.6):** узкая полоса у берега (shore_start/end_blend уже есть — сузить),
   на гребнях моря пенящиеся волны (группа Foam) ослабить; на озере почти нет.
7. **Ночь (4.7):** существующий `update_sky` (глубинные цвета гаснут с небом,
   albedo_fresnel от горизонта) не ломается — только базы заменяются на BU-цвета;
   дорожка луны — спекуляр шейдера, уже есть.
