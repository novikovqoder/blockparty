# Меч героя Born Unblessed — комплект и находки

Меч висит на левом бедре. Колёсико мыши листает слоты «руки ↔ меч».
При выборе меча играет анимация «достать меч», и в момент, когда ладонь легла на
рукоять, меч перецепляется с пояса в руку. При выборе рук — «убрать меч» и обратно на пояс.
Без анимаций меч просто плавно переносится.

Комплект проверен в Godot 4.7.2 на тестовом герое со скелетом Mixamo: перенос анимаций
из файлов пака с исходными именами, выхватывание, удар, убирание. 6 тестов GUT зелёные.

## Состав

| Путь | Что это |
|---|---|
| `assets/sword_bu/sword_bu.glb` | Модель меча, 1,1 м. Начало координат — центр рукояти, клинок вдоль +Y, кромки вдоль ±X. Текстура и металл/шероховатость внутри. |
| `scripts/hero_bu/weapon_mounts_bu.gd` | `WeaponMountsBU`: хват в ладони, место на поясе (из анимации выхватывания или по бедру), префикс костей. |
| `scripts/hero_bu/equip_controller_bu.gd` | `EquipControllerBU`: слоты, колёсико, перецепка по анимации, сигналы. |
| `scripts/hero_bu/hand_grip_bu.gd` | `HandGripBU` (по желанию): сжимает пальцы в кулак поверх анимации. |
| `tools/retarget_mixamo_bu.gd` | Перенос анимаций Mixamo (FBX) на скелет героя -> `AnimationLibrary` (.res). |
| `tools/capture_sword_bu.gd` | Скриншоты проверки: пояс → достаёт → стойка → удар → убирает → пояс. |
| `tests/test_sword_bu.gd` | Тесты GUT (скелет собирается в тесте, от модели героя не зависят). |
| `docs/screenshots/sword_bu/` | Эталонные скриншоты проверки на тестовом герое (рыцарь из Meshy, в игру не идёт). |

## Требования к герою

- Скелет **Mixamo** (кости `Hips`, `Spine`, `RightHand`, `RightHandIndex1`, `RightHandMiddle1`,
  `RightHandPinky1`, `LeftUpLeg` …). Префикс (`mixamorig_`, `mixamorig1_`, без префикса)
  определяется сам по кости `*Hips`.
- Godot при импорте меняет `:` на `_`: `mixamorig:RightHand` → `mixamorig_RightHand`.
  В коде и `BoneAttachment3D` — только вариант с `_`.
- Если скелет **не Mixamo** — перенос анимаций этим инструментом не подойдёт; нужен
  ретаргет через `SkeletonProfileHumanoid` при импорте. Код меча (хват, пояс) тоже
  опирается на имена Mixamo.

## Как подключить

1. Перенести анимации пака на героя (один раз, результат — ресурс библиотеки):
   ```
   xvfb-run -a godot --path . --rendering-driver opengl3 --rendering-method gl_compatibility \
     -s res://tools/retarget_mixamo_bu.gd -- <сцена героя> <папка с FBX пака> res://assets/hero/hero_sword_anims.res
   ```
   Имена анимаций получаются из имён файлов: `sword and shield idle (2).fbx` → `ss_idle_2`,
   `draw sword 2.fbx` → `draw_sword_2`. `X Bot.fbx` пропускается. Ожидается 51 анимация,
   `static=1` — нормально (`ss_crouch_block_idle` почти без движения рук).
2. Подключить библиотеку к `AnimationPlayer` героя под именем `sword`
   (анимации станут `sword/ss_idle`, `sword/draw_sword_2` …).
3. Добавить герою дочерний узел `EquipControllerBU`:
   - `skeleton_path` — Skeleton3D героя, `animation_player_path` — его AnimationPlayer;
   - `sword_scene` — `res://assets/sword_bu/sword_bu.glb`;
   - `unarmed_idle_animation` — стойка героя без оружия (пусто — не переключать).
4. Сигналы: `slot_changed(slot)` — сразу при выборе, `equip_finished(slot)` — когда
   анимация снаряжения закончилась и можно возвращать анимации движения.
   `busy == true`, пока идёт смена — в это время контроллер движения не должен
   перебивать анимацию.

## Находки (почему сделано именно так)

- **Хват по диагонали ладони.** Рукоять лежит от пятки ладони к основанию указательного
  пальца под 35° к поперечной линии ладони, клинок выходит со стороны большого пальца.
  Ровно поперёк ладони меч выглядит «воткнутым» и на поясе висит горизонтально.
  Точка хвата — 72 % пути от кисти до основания среднего пальца и 3,2 см в сторону ладони.
  Всё считается из положения костей пальцев, поэтому подходит любой герой Mixamo.
- **Место на поясе берётся из анимации выхватывания.** В момент контакта (кадр, где ладонь
  на рукояти: `draw_sword_2` — 0,03 с) считается, где окажется меч в руке, и туда же
  (относительно таза) вешается меч на поясе. Тогда при перецепке меч не прыгает.
  Запасной вариант без анимации — `sheath_on_hip()`: левое бедро, клинок вниз и назад на 28°.
- **Перецепка в момент контакта.** `draw_sword_2` — 0,03 с, `sheath_sword_1` — 1,16 с.
  Меч перецепляется с сохранением положения на экране и за 0,2 с доводится до места
  (`blend_time`) — без рывка.
- **Запекание анимаций — только в игровом цикле.** Вне `_process` вызов `seek()` не обновляет
  позу скелета: получаются «статичные» анимации. Инструмент печатает, на сколько сдвинулась
  рука в каждой анимации; если `static` много — что-то не так.
- **Без выравнивания корпуса и головы.** При переносе между A-позой и T-позой руки и ноги
  выравниваются по направлению кости, а таз, позвоночник, шея и голова — нет. Иначе
  голова во всех анимациях задрана вверх, корпус гнётся (проверено на опыте).
- **Ножны не нужны** (решение владельца): меч висит на поясе открытым клинком.

## Проверка

- Тесты: `godot --headless --path . -s addons/gut/gut_cmdln.gd -gdir=res://tests -gexit`
  (в том числе `tests/test_sword_bu.gd`, 6 тестов).
- Скриншоты:
  ```
  xvfb-run -a godot --path . --rendering-driver opengl3 --rendering-method gl_compatibility \
    --resolution 1280x960 --fixed-fps 30 -s res://tools/capture_sword_bu.gd -- \
    <сцена героя> res://assets/hero/hero_sword_anims.res docs/screenshots/<этап>/
  ```
  В консоли для каждого снимка пишется, где меч (`HipMount` / `RightHandMount`) и какая
  анимация играет. Ожидается: 01 и 07 — пояс, 02–06 — рука.

## Лицензии

- Модель меча: сгенерирована владельцем проекта в Meshy (бесплатный тариф, CC BY 4.0 —
  нужен кредит «Meshy» в титрах). Текстура нарисована процедурно для этого проекта.
- Анимации Mixamo в комплект **не входят** (пак уже есть на сервере). Mixamo разрешает
  использовать анимации в играх, но не распространять сами файлы — не класть FBX в
  публичный репозиторий.
- Код комплекта написан для проекта.
