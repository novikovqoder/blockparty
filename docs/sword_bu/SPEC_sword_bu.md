## П5.N — Меч героя (на поясе, колёсико «руки ↔ меч»)

Цель: у героя игры (выбранного по итогам этапа П5.10 «Персонажи») появляется меч. Меч висит на левом бедре, колёсико мыши
переключает слоты «руки» и «меч», выхватывание и убирание идут по анимациям Mixamo
из «Pro Sword and Shield Pack» (51 анимация, уже лежит на сервере).

Комплект: `assets/sword_bu/`, `scripts/hero_bu/`, `tools/retarget_mixamo_bu.gd`,
`tools/capture_sword_bu.gd`, `tests/test_sword_bu.gd`, описание — `docs/sword_bu/README.md`.

Требования:
1. Анимации пака переносятся на скелет текущего героя инструментом
   `tools/retarget_mixamo_bu.gd` в библиотеку `assets/hero/hero_sword_anims.res`
   (51 анимация, имена вида `ss_idle`, `ss_slash`, `draw_sword_2`, `sheath_sword_1`).
   Исходные FBX лежат в `assets_src/mixamo_sword/`, эта папка в `.gitignore`
   (файлы Mixamo не распространяем). В git — только готовая библиотека.
2. Библиотека подключена к AnimationPlayer героя под именем `sword`.
3. Герою добавлен `EquipControllerBU`: меч `assets/sword_bu/sword_bu.glb`,
   выхватывание `sword/draw_sword_2` (контакт 0,03 с), убирание `sword/sheath_sword_1`
   (контакт 1,16 с), стойка с мечом `sword/ss_idle`, стойка без меча — текущая idle героя.
4. Колёсико вверх/вниз листает слоты; во время смены (`busy`) движение героя не
   перебивает анимацию снаряжения; после `equip_finished` возвращаются обычные анимации.
   С мечом в руке ходьба/бег/атака используют `sword/ss_walk`, `sword/ss_run`, `sword/ss_slash`,
   если у героя есть соответствующие состояния (иначе — отметить в STATUS.md, что не подключено).
5. Если скелет героя не Mixamo — этап останавливается, владельцу сообщается, что нужно
   для ретаргета; код комплекта не переписывается под другой скелет без согласования.
6. Приёмка: тесты GUT зелёные, включая `tests/test_sword_bu.gd`; скриншоты
   `tools/capture_sword_bu.gd` в `docs/screenshots/П5.N/` (01 и 07 — меч на поясе,
   02–06 — в руке); STATUS.md обновлён; сборка для Windows; кредит «Meshy» (модель меча,
   CC BY 4.0) добавлен в титры/LICENSES.
