Клешня, новый этап: **П11 — графика на максимум** (ветка `born-unblessed`).

Комплект `born_unblessed_gfx_ultra_kit.zip` лежит в `~/`. В нём только ТЗ, кода нет — код пишет Claude Code.

1. Распакуй в проект без перезаписи:
   `cd ~/blockparty && git checkout born-unblessed && git pull && unzip -n ~/born_unblessed_gfx_ultra_kit.zip`
2. Покажи мне `docs/gfx_ultra/SPEC_gfx_ultra.md` и с моего согласия допиши его в `docs/SPEC.md` как раздел П11.
3. Запусти Claude Code в `~/blockparty` с задачей:
   «Этап П11 по docs/gfx_ultra/SPEC_gfx_ultra.md. Сначала покажи план файлов и изменений.
   Главное: настройка "Качество графики" из меню Born Unblessed должна реально управлять миром
   (сейчас игра её игнорирует), и нужен новый уровень ULTRA: SDFGI, SSIL, SSR, SSAO/SSIL Ultra,
   тени 8192 с мягким фильтром Ultra, объёмный туман высокого качества, MSAA 4x + SMAA, полная
   детализация LOD. TAA не включать. Героя, анимации, палитру и тонмап не трогать.
   Скриншоты, съёмки и замеры FPS не делать. Тесты GUT — обязательно».
4. Принимаешь этап, если: GUT зелёный (включая `tests/test_gfx_ultra.gd`), STATUS.md обновлён,
   коммит и push в `born-unblessed`, собрана Windows-сборка `builds/born-unblessed-windows.zip`.
   В `main` не сливать.
5. Остановись и позови меня, если: Claude Code хочет что-то скачать или установить; хочет менять
   героя, анимации или вид тумана/цвета; тесты не зеленеют после трёх попыток; нужен force push.
6. Отчёт мне — коротко: что сделано, что не получилось, где сборка. Визуал и FPS проверю сам.
