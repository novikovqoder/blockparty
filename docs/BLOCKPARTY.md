# Blockparty — описание текущей реализации

> Версия документа: 1.3 (2026-10-13). Соответствует ветке `p5.8-realism-v2`, ТЗ SPEC 2.6.
> Принятые этапы: П0–П5.7. Этап П5.8 «Реализм, попытка 2: Лес и редактор
> внешности» готов и ждёт одобрения владельца по скриншотам и видео
> (`docs/screenshots/P5.8/`); в `main` не сливается до одобрения.
> Документ живой: разделы обновляются по мере развития проекта.

## 1. Общее описание

**Blockparty** — социальный 3D открытый мир для Steam (Windows) в «более-менее
реалистичном» стиле: до 12 незнакомцев гуляют по острову, знакомятся, вместе
проходят небольшие активности и общаются голосом по кнопке. Никаких целей
«на скорость»: награждаются помощь и совместные действия.

- Ориентир по ощущению — Sky: Children of the Light.
- Стиль — реалистичный (решение владельца): с П5.7 — земля, небо
  и растительность Леса, с П5.8 — люди, собираемые в редакторе внешности
  из CC0-частей. Остальные зоны до следующего этапа остаются в прежнем виде.
- Цель MVP — проверить гипотезу: люди, поставленные в ситуации, где без
  кооперации не пройти, начинают разговаривать и хотят сыграть ещё раз
  той же компанией.
- Забег... мир: постоянный остров, вход в любой момент, длительность сессии свободная.
- Разработка ведётся на Linux-сервере: владелец ставит задачи, Claude Code пишет код,
  агент OpenClaw (Клешня 🦞) запускает прогоны, принимает этапы и сливает ветки.

## 2. Технологии

| Компонент | Решение |
| --- | --- |
| Движок | Godot 4.7.2 stable, рендерер Forward+ |
| Язык | GDScript со строгой статической типизацией |
| Steam | GodotSteam 4.22.1 (GDExtension) — лобби, приглашения, голос, relay |
| Тесты | GUT 9.7.1 — 290 тестов (36 файлов), все зелёные |
| Сеть (разработка) | ENet, встроенный в Godot — несколько копий на одном ПК без Steam |
| Сеть (прод) | Steam Datagram Relay поверх SteamMultiplayerPeer, IP скрыты |
| Контроль версий | Git + Git LFS; GitHub `novikovqoder/blockparty` |
| Персонажи | Quaternius Universal Base Characters + Modular Character Outfits (CC0), анимации Quaternius Universal Animation Library 1/2 на риге UBC |
| Ассеты | Только CC0: Quaternius (персонажи, одежда, анимации), Poly Haven + ambientCG (Лес, текстуры, HDRI), Kenney (остальные зоны); реестр в `assets/third_party/LICENSES.md` |

Соглашения: 1 юнит = 1 метр = 1 блок; все числа геймплея — в `gameplay/balance.tres`;
сетевые константы — в `net/protocol.gd` (PROTOCOL_VERSION = 4); весь UI — ru/en
через `tr()`.

## 3. Мир

- **Остров, 6 зон:** Площадь (спавн, костёр), Лес, Руины, Холмы, Расщелина, Озеро.
- **Генерация по seed (детерминированная):** рельеф — процедурный меш по карте
  высот (ArrayMesh + коллизия HeightMapShape3D); предметы — процедурные меши
  и CC0-модели. 8 388 инстансов (перепечён в П5.8); одинаковый seed даёт
  бит-в-бит одинаковый
  остров (закреплено тестом на хеш).
- **Время мира:** цикл дня и ночи с закатом; мировое событие — **Маяки и Звездопад**.
- **Атмосфера:** тёплое солнце, высотная дымка, туман по зонам (гуще в Лесу
  и у Озера), glow огня и фонарей, тональная коррекция; режимы «Простая
  графика» / «Высокое качество».
- **Карта острова** — по клавише M.
- **Зона Лес — реалистичная (П5.7, доделана в П5.8):** земля шейдером
  смешивания (уклон → камень/мох, низины → влажная земля, тропы →
  утоптанная, остальное — подстилка с травой), растительность Poly Haven
  по seed-вариациям, ориентир-сцены (поляна гиганта, овраг с мостиком
  из брёвен), HDRI-небо с переходами суток, объёмный туман. П5.8: листва
  фотограмметрии с альфа-вырезкой, небо без лишнего тумана, мягкая граница
  зоны. Остальные зоны — в прежнем виде, раскатка стиля — следующий этап.

## 4. Внешность игрока

**Редактор внешности** (кнопка «Персонаж» в главном меню, П5.8): слева модель
в полный рост — мышь вращает с инерцией, колёсико — зум, 3 с без ввода модель
поворачивается сама; студийный свет (ключевой, контровые, подсветка лица).
Справа панель выбора:

- **Пол:** мужское/женское тело.
- **Причёска:** 6 вариантов (длинные, пучки, «под ноль» ×2, с пробором,
  борода — по полу списки свои).
- **Цвета:** волосы (10 естественных), кожа (8 оттенков), глаза (6 цветов).
- **Одежда:** верх, низ и обувь из комплектов Peasant / Ranger
  (Quaternius Modular Character Outfits).
- **Головной убор:** «без», капюшон Ranger, панама с веточкой, шляпа
  с ракушкой, кепка с «ушками» (уборы жителей — процедурные меши).
- Кнопка **«Случайно»** собирает валидную комбинацию.

Персонаж **всегда одет**: «без» бывает только головной убор — тело под одеждой
удалено при запечке, видны голова, глаза, брови и причёска (тест «всегда одет»).
«Выбрать» сохраняет внешность в `user://` и возвращает в меню, «Назад» —
без сохранения.

- **Цвет игрока:** 6 ярких вариантов на верхней одежде; выдаётся по хэшу
  Steam ID (в ENet — по peer id), постоянен между сессиями.
- **Анимации** (Quaternius UAL 1/2 на риге UBC, П5.8): покой, ходьба, бег,
  прыжок (взлёт/полёт/приземление), помахать, сесть; жесты эмоций
  (спасибо, «вон там», «подожди», смешно, «помогите!»); вытягивание
  из расщелины, вис у кромки, подтягивание наверх, «за руку». Локомоция
  выбирается локально по скорости и касанию земли — без сетевого трафика.
- **Внешность по сети:** при входе в мир передаётся компактной структурой —
  9 байт индексов (пол, причёска, верх, низ, обувь, убор, цвета волос/кожи/
  глаз); хост проверяет диапазоны. PROTOCOL_VERSION поднят до 4, миры
  с другой версией не показываются. Боевые клипы UAL (замах, выстрел,
  каст, получение удара, уклонение) проверены на риге — задел на будущее,
  в игру не подключены.

## 5. Жители

Трое жителей острова — NPC с заданиями (П5.5), собираются той же системой
внешности, что и игроки (фиксированные пресеты, Quaternius UBC + одежда,
фирменные уборы — процедурные):

| Житель | Убор | Девиз | Задание |
| --- | --- | --- | --- |
| **Финн** | кепка с меховыми «ушками» | «Лучшая тропа — та, по которой идут вдвоём» | «Короткая тропа» |
| **Луми** | шляпа с ракушкой на ленте | «Маяки не спорят, кто ярче, — просто светят» | «Зажги маяки» |
| **Тимьян** | панама с веточкой мяты | «От чая с мятой ещё никто не отказывался» | «Вечерний чай» |

Характеристик у персонажей больше нет (П5.8): все игроки равны — одна скорость
бега, одна высота прыжка, вытягивание и подсадка с базовыми параметрами.
Жители видны всегда; девиз показывается в диалоге задания. Тексты — в правимом
`gameplay/player/characters.json`.

## 6. Механики

**Управление:** WASD/стрелки, Shift — шаг, Пробел — прыжок, **E** — взаимодействие,
**F** — «за руку», **Q** (удерживать) — колесо эмоций, **1–6** — быстрые эмоции,
M — карта, Tab/Esc — меню/список игроков.

- **Вытягивание из расщелины:** упавший висит у края с таймером; помощь —
  удержание E рядом (0.5 с), помощнику +3 монеты, событие в «Встречи».
  Соло: таймер → чекпоинт.
- **Ворота руин:** открываются, когда на плитах стоят N разных игроков; сундук
  за ними. Соло-путь: стоять у закрытых ворот 60 с — откроются сами.
- **Смотровые уступы:** недостижимы обычным прыжком; подсадка — прыжок с головы
  другого игрока (×1.3). Соло-пути: лестница опускается через 60 с, есть
  обходная тропа.
- **Золотой светлячок:** убивается ударами двух разных игроков в пределах 3 с,
  награда каждому. В одиночном мире — один удар.
- **«За руку» (F):** приглашение на 5 с, цепочка до 4 игроков; движение со
  скоростью более медленного; ведомый повторяет прыжки ведущего; разрыв по F
  или дистанции >4 м. Каждые 30 с в связке — очки «Встреч».
- **Костёр (Площадь):** 8 мест, E — сесть, любое движение — встать; когда сидят
  двое и больше, огонь разгорается (свет, радиус, искры).
- **Эмоции:** колесо Q + быстрые 1–6, пузырь над головой 2.5 с, жесты —
  анимации Universal Animation Library; кулдаун 1 с; «Сюда!» — маркер-стрелка
  на 5 с; «Помогите!» — стрелка над игроком.
- **Мобы:** птица, зверёк, золотой светлячок — траектории детерминированы
  от seed и времени мира; решения «убит/подобран» принимает хост.
- **Монеты:** статичные на острове + награды за помощь, ворота, светлячка;
  счётчик в HUD, хранятся локально в `user://save.json`.
- **Задания жителей (П5.5):** «Вечерний чай» (5 пучков мяты в Лесу → сесть у
  костра → пар и светлячки), «Зажги маяки» (3 маяка удержанием E, вдвоём
  быстрее → мини-звездопад), «Короткая тропа» (4 вехи к Руинам → светящаяся
  тропа + быстрые ворота). Задания общие для мира (world_state), награда
  каждому участнику, повторно — со следующего рассвета; трекер в HUD и точки
  целей на карте.
- **Все механики проходимы в одиночку** — запасные пути встроены в каждую.

## 7. Сеть и Steam

- **Топология listen-server:** создатель мира — хост и играет; клиент
  авторитетен только за движение своего персонажа (снапшоты 20 Гц,
  интерполяция ~100 мс, AOI).
- **Вход в мир в любой момент** (`world_state`): опоздавший видит тех же мёртвых
  мобов, подобранные монеты и внешности всех игроков.
- **Транспорт взаимозаменяемый:** ENet для разработки, Steam Datagram Relay
  для прода; остальной код не знает разницы.
- **Steam (этап П4, ожидает ручной проверки на двух ПК):** лобби-миры «В мир» /
  «Мир для друзей», приглашение через оверлей, `+connect_lobby`, Rich Presence.
  Тестовый App ID 480 с обязательным фильтром по тегу `blockparty`.
- **Отладка:** боты `--bot`, эмуляция сети `--net-lag=150 --net-loss=5`,
  `--debug-collisions` (визуализация форм), F3-панель.

## 8. Сборка и запуск

- **Сборка:** `tools/build_windows.sh` → `builds/blockparty-windows.zip`
  (226 МБ): `blockparty.exe` (PCK встроен),
  `libgodotsteam.windows.template_release.x86_64.dll`, `steam_api64.dll`,
  `steam_appid.txt`; описание сборки — `builds/BLOCKPARTY.md` (копия этого
  документа из `docs/`).
- **Запуск без Steam:** exe → окно «Steam не запущен» → «Играть офлайн».
- **Dev-аргументы** (после `--`): `--dev-host`, `--dev-join=IP`, `--dev-name`,
  `--dev-seed`, `--dev-spawn=plaza|forest|ruins|hills|crevasse|lake`, `--bot`,
  `--net-lag`, `--net-loss`, `--debug-collisions`, `--log-net`.
- **Тесты:** `godot --headless -s addons/gut/gut_cmdln.gd` — все зелёные.
  E2E заданий: `tools/quest_e2e.sh` — две headless-копии (ENet), проверяет,
  что задание видно обоим и награда приходит каждому участнику.

## 9. Структура проекта

```
autoload/     автолоады: net, session, steam_service, event_bus, dev, settings, save, log

              world (остров, костёр, атмосфера), mobs, activities

scenes/       boot, меню, редактор внешности, world_scene
ui/           HUD, панели, тема
assets/       палитры, third_party/ (quaternius.com, kenney.nl, polyhaven.com,
              ambientcg.com + LICENSES.md)
i18n/         strings.csv (ru/en)
tests/        36 файлов GUT
tools/        build_windows.sh, screenshots.sh, shoot_series.sh (GIF-клипы),
              generate_island, запекатели UBC/анимаций/уборов, диагностика
docs/         SPEC.md (2.6), STATUS.md (отчёты этапов), BLOCKPARTY.md, archive/
```

## 10. Статус и планы

**Принято и слито в main:** П0 каркас · П1 персонаж и камера · П2 остров ·
П3 сеть ENet · П4 Steam · П4.5 low-poly (v2.1→v2.2 с переделкой земли) ·
П5 активности и социальные механики · П5.5 задания жителей (ТЗ 2.4) ·
vfx-fix (5 багов + 6 визуальных блоков) · П5.7 реалистичный Лес и персонажи
(ТЗ 2.5). Сравнение «было—стало» — `docs/screenshots/P5.7/compare/`.

**В ветке `p5.8-realism-v2` (ждёт одобрения):** П5.8 «Реализм, попытка 2:
Лес и редактор внешности» (ТЗ 2.6) — фиксы Леса, редактор внешности на
Quaternius UBC + MCO, анимации UAL на риге UBC, характеристики убраны,
жители пересобраны той же системой. Материалы для проверки — `docs/screenshots/P5.8/`
(склейки «было—стало», тур редактора, экипаж, жители, GIF-клипы движений).

- П6 — голосовой чат 3D (push-to-talk, затухание к 50 м, у костра слышно всех);
- П7 — экран «Встречи», симпатии, «Добавить в друзья», история сессий;
