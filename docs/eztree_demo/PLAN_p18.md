# П18-ПЕРЕСБОРКА «Как в демо ez-tree» — план (Сборка 1: деревья + свет)

Ветка `born-unblessed` от 449a691. Справочник — исходники демо в
`docs/eztree_demo/src/` (скачаны с raw.githubusercontent.com, ветка master;
в репо это то же дерево, что и main). Сборка 2 (трава/цветы, пп. 5–8) —
следующим прогоном.

## Выжимка формул демо (сверено с исходниками)

**Деревья** (`src/lib/tree.js`):
- `generateLODs`, уровни `defaultLODLevels`: LOD1 — дистанция 100 ед.,
  hysteresis 0.05, detail `{sectionStride 3, segmentFactor 0.75,
  leafStride 2, leafScale 1.25}`; LOD2 — 250 ед., hysteresis 0.05,
  `{sectionStride 6, segmentFactor 0.4, leafStride 2, leafScale 1.3,
  billboard Single}`. Ветер листвы (#createLeafMaterial):
  `windSway = uv.y * uWindStrength(0.5,0,0.5) * (0.5·sin(t·0.5+φ)
  + 0.3·sin(2t·0.5+1.3φ) + 0.2·sin(5t·0.5+1.5φ))`, фаза
  `φ = 2π·simplex3(pos/70)` — уже в canopy.gdshader с П5.9, сохраняется.
- Материалы: MeshStandardMaterial (PBR движка), roughness 1, metalness 0,
  тинт пресета; листва DoubleSide + alphaTest пресета + dithering;
  roundedNormals (options.js:162, default true → все пресеты демо):
  `n_i = normalize(направление_листа + (v_i − центр_листа))`, БЕЗ переворота
  нормали задней грани (в three.js отключали `normal *= faceDirection`).
  В GLB наших деревьев эти нормали уже запечены генератором.
- Свет (`skybox.js`, `main.js`, `scene.js`): DirectionalLight intensity 5,
  AmbientLight белый 0.4, NeutralToneMapping (в Godot 4.7.2 отсутствует —
  проверено: enum = Linear/Reinhard/Filmic/ACES/AgX; ближайший — AgX,
  уже стоит в сцене), exposure 2, FogExp2 0x94b9f8 плотность 0.0015/ед.,
  тени PCF 512×512 на ортокамере ±100 ед. (≈2.6 текселя/м), SMAA.

**Трава** (`src/app/grass.js`) — Сборка 2, здесь только справка: одна модель
(3 скрещенные плоскости, 6 треугольников), InstancedMesh 5000/25000,
size {5,4,5} ± variation {1,2,1}, yaw случайный, цвет экземпляра
(0.25+0.1r, 0.3+0.3r, 0.1), материал ×0.6, emissive 0x308040 ×0.05,
пятнистость simplex scale 100 patchiness 0.7, ветер = формула травы
(sin·cos по position.y), тени отдаёт и принимает; цветы — 3 модели по 50
шт. тем же шумом.

**Масштаб**: k = целевая высота / высота GLB; по manifest.json k = 0.10–0.11
(кусты), 0.22–0.29 (лиственные), 0.32–0.38 (ели); ориентир владельца —
ель large k ≈ 0.38. Пересчёт плотности тумана: демо-ед. → метры ×k
обратной стороной: density_m = 0.0015/k.

## Границы LOD

Демо 100/250 ед. через k даёт 22–95 м по видам — но мир у нас крупнее сцены
демо (камера там ≤150 ед.), поэтому границы — константы из п.3 задания:
**70 м и 150 м** (единые на группу деревьев, гистерезис 5 %), с ползунком
F3 «Детализация деревьев» (множитель 0.5–2×). Отмечу: сейчас дальние
уровни управляются visibility_range у MultiMeshInstance3D, который в Godot
считается по AABB всей ноды — а AABB группы это весь остров, так что при
ходьбе по острову фактически всегда виден только ближний уровень. Новая
схема (переключение уровней группы по дистанции до ближайшего дерева)
заодно это чинит.

## Изменения по блокам (чекпоинт = коммит + push)

### Блок 1. Материалы как в демо
- `assets/shaders/tree_bark.gdshader`: убрать `light()` (wrap-Ламберт,
  sky_fill, ручной спекуляр) — стандартный PBR Godot; ALBEDO = текстура ×
  инстанс-тон, NORMAL_MAP, ROUGHNESS из карты; METALLIC 0. Uniform
  bark_specular убрать.
- `assets/shaders/canopy.gdshader`: убрать `light()` и render_mode
  `specular_disabled`; ALBEDO = текстура × тинт × COLOR (AO), alpha
  scissor по alpha_cut (пресет, был), a2c_edge (П17, был), ветер демо
  (был), cull_disabled (был). Godot сам не переворачивает нормаль задней
  грани (нет аналога `normal *= faceDirection`) — условие демо выполнено
  по умолчанию, отмечу в комментарии шейдера.
- `gameplay/world/props/eztree_meshes.gd`: `_bake_crown` больше не пишет
  сферические нормали — нормали листвы берутся из GLB (= roundedNormals
  генератора); AO глубины кроны в COLOR.rgb остаётся (галочка «Объём
  кроны» продолжит гасить его через volume_mix, микс нормалей убрать).
- Перезапечь `gameplay/world/island_art.res` (tools/generate_island.gd):
  хеш высот/генератора не меняется (тест-контроль 941246210).
- Тесты: `tests/test_canopy_bake.gd` — нормали сверяются с GLB-оригиналом
  (GLTFDocument читает `*_lod*.glb`, нормали после ×k неизменны);
  AO/тон/хех-тесты остаются; новый тест «в шейдерах нет void light()».

### Блок 3. LOD умнее демо
- `eztree_meshes.gd`: `build_set` возвращает ближний уровень как гибрид —
  ветки LOD1 демо + полная листва LOD0 («листва НЕ трогается»); lods =
  [LOD1 демо, LOD2 демо]. Полный меш веток LOD0 больше не используется.
- `island_view.gd`: три ноды-уровня на группу без visibility_range;
  IslandView в update_viewer меряет дистанцию до ближайшего дерева группы
  и ведёт уровень с гистерезисом 5 % (70 м → LOD1, 150 м → LOD2); переход —
  плавное перетекание по времени 0.4 с: старому уровню alpha_cut листвы
  анимируется от порога пресета до 1.0 (полное отсечение), встречному —
  от 1.0 к порогу; смена веток (уровни 1↔2, дальние) — мгновенная
  (незаметна за туманом). Никакого FADE_SELF/дизеринга по расстоянию.
- F3: ползунок «Детализация деревьев» (множитель границ), галочка
  «LOD-перетекание» (блок 5, вкл/выкл плавности).
- Тесты: состав гибрида (вершины листвы = LOD0 GLB, веток = LOD1 GLB);
  границы и гистерезис; у нод нет FADE_SELF; перетекание двигает alpha_cut
  и после конца возвращает порог пресета.

### Блок 4. Тени деревьев
- Тени — только у ближнего уровня (LOD0-гибрид, cast_shadow ON); LOD1/LOD2
  без тени. Мягкость: демо PCF 512×512 на 200×200 ед. ≈ 2.6 текс/м; у нас
  на HIGH атлас 4096, 4 сплита PSSM, max_distance 70 м, blur 1.7–2.6 —
  текселей на метр у ближнего сплита больше, размытие не хуже демо
  (обоснование в STATUS).
- F3: галочка «Тени деревьев» (вкл/выкл cast_shadow у уровней).
- Тесты: тень по уровням, галочка.

### Блок 5. Пресет света ezTree (DayCycle)
- Пресет «ezTree» (по умолчанию) и «текущий»; действует на ДЕНЬ
  (dayness), ночь/закат — как сейчас, переходы плавные (lerp по dayness).
  - Солнце: сильнее базы (соотношение direct:ambient демо ≈ 12:1;
    конкретные числа — в Balance-полях пресета, см. STATUS).
  - Ambient: ровный белый, ~0.4-эквивалент при SKY-источнике.
  - Тонмап: AgX (Neutral в 4.7.2 нет — проверено; AgX ближайший по
    сохранению хроматики и мягкому спаду, уже в сцене), экспозиция дня
    ближе к демо (2.0 у демо; с AgX подберу 1.5–2.0, число в STATUS).
  - Туман (только в пресете): цвет 0x94b9f8, экспоненциальный,
    плотность 0.0015/k по k ели large (0.38) ≈ 0.004 на метр
    (0.0067 по медиане k 0.224 — диапазон упомяну в STATUS).
- F3: галочка «Свет: ezTree» (по умолчанию вкл), «LOD-перетекание» (из
  блока 3). Авто-замер F3 забирает новые галочки автоматически (EFFECTS).
- Тесты: пресет меняет fog_density/цвет/экспозицию/энергию солнца днём;
  ночью значения остаются от ночи (тёмная ночь); галочки в EFFECTS.
