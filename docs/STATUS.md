### Этап 0 — Каркас проекта (2026-09-27)

**Сделано:**
- `project.godot`: автолоады в порядке зависимостей, окно 1280×720,
  stretch `canvas_items`/`keep_height`, рендерер `gl_compatibility`,
  переводы ru/en (fallback `en`), иконка.
- Структура папок из раздела 3 SPEC (`net/`, `gameplay/…`, `scenes/`, `ui/`,
  `assets/`, `i18n/`, `tests/`, `tools/`).
- Автолоады: `log.gd` — полностью рабочий (консоль + `user://logs/game_*.log`,
  хранятся последние 10); `steam_service.gd` — инициализация Steam, при успехе
  пишет в лог SteamID и persona name; `dev.gd` — разбор всех аргументов из
  раздела 3 (`--dev-host`, `--dev-join`, `--dev-name`, `--dev-seed`, `--bot`,
  `--net-lag`, `--net-loss`, `--log-net`); остальные (`event_bus`, `settings`,
  `save`, `net`, `session`, `voice`, `interactions`) — заглушки с комментариями
  «что делает / чего не делает»; `net.gd` и `session.gd` уже логируют выбранный
  dev-режим и seed.
- Сцены: `boot.tscn` (ждёт Steam; без Steam — окно «Steam не запущен» с кнопками
  «Играть офлайн (режим разработки)» и «Выход»), заглушки `main_menu`, `lobby`,
  `run`, `results`. Локализация через метаданные `tr_key` (`ui/loc_labels.gd`).
- GodotSteam подключён (уже был в `addons/`); имена API сверены с фактически
  установленной библиотекой вызовами в headless: `steamInitEx(480, true) ->
  Dictionary{status, verbal}`, `status == 0` — успех, `getSteamID()`,
  `getPersonaName()`. Примечание: сайт godotsteam.com с этого сервера недоступен,
  использована локальная документация аддона + фактические сигнатуры ClassDB.
- GUT настроен (`.gutconfig.json`), тест `tests/test_dev_args.gd` — 6 тестов,
  21 проверка, все зелёные.
- `tools/run_local.sh` (хост + N клиентов, `--headless` для сервера, cleanup по
  Ctrl+C) и `tools/run_local.ps1` для Windows.
- `assets/CREDITS.md` заведён (пока только `icon.svg`).
- Версии записаны в README.

**Как проверить на сервере (headless):**
- `godot --headless --quit` — запуск без ошибок, в логе офлайн-ветка Steam.
- `godot --headless --quit -- --dev-host --dev-seed=42 --net-lag=150` — в логе
  разобранные аргументы (Net, Session).
- `godot --headless -s addons/gut/gut_cmdln.gd` — все тесты зелёные.
- `tools/run_local.sh 3 --headless` — 4 процесса, затем Ctrl+C убирает все.

**Как проверить вручную (ПК с Windows):**
- Открыть проект в Godot 4.7.2, запустить: без запущенного Steam — окно
  «Steam не запущен», кнопка «Играть офлайн» ведёт в меню-заглушку.
- С запущенным Steam: в логе `user://logs/game_*.log` — SteamID и persona name,
  загрузка сразу в меню.
- `tools/run_local.ps1` — 4 окна игры (пока просто заглушки меню, реальная
  сеть — этап 2).
- Переключить язык системы на en — интерфейс на английском.

**Отложено:**
- Реальная сеть ENet (этап 2), боты (этап 2), Steam-лобби (этап 4).
- Настройки/сохранения: чтение-запись `config.cfg`/`save.json` (этап 7).
- `ui/theme.tres`, шрифт с кириллицей (этапы 1+; сейчас системный шрифт Godot).

**Известные проблемы:**
- После клонирования репозитория нужен `godot --headless --import` — без него
  переводы не сгенерируются (`.translation` в `.gitignore`).
- Без установленного GodotSteam автолоад `SteamService` не скомпилируется;
  в MVP аддон всегда в репозитории, поэтому допустимо.

### Этап 1 — Одиночный геймплей (2026-09-27)

**Сделано:**
- `gameplay/balance.gd` + `balance.tres` — все числа разделов 4–6 SPEC
  (движение, прыжок, coyote/буфер, атака, мобы, монеты, лимиты забега);
  `assets/palette.gd` + `palette.tres` — пастельная палитра плейсхолдеров.
- Игрок (`gameplay/player/`): CharacterBody2D 28×44 — ускорение/торможение
  1800/2200, в воздухе 70%, прыжок 520 с coyote 0.10 с и буфером 0.10 с,
  переменная высота (отпускание режет скорость до 45%), гравитация 1400
  (×1.4 при падении, max 900), атака J/ЛКМ (хитбокс 40×32, 0.12 с активен,
  перезарядка 0.35 с), неуязвимость/мигание 1 с от шипов, состояние «Висит»
  (8 с, кнопка «Сдаться»), Camera2D со сглаживанием, опережением по бегу и
  лимитами уровня. Визуал — отдельная сцена `player_visual.tscn`
  (блочный кубик, анимации твинами).
- Мобы: `bird` (синусоида вдоль участка), `critter` (туда-обратно) — позиция
  чистая функция `f(params, run_time)`, без randi()/randf(); смерть по
  подтверждению (раздел 6): клиент играет эффект сразу, «хост» проверяет
  дистанцию 96 px; +1 монета. Монеты — «первый коснувшийся», через тот же
  путь подтверждения. На этапе 1 роль «хоста» локально исполняет сцена
  забега — на этапе 2 логика переедет в сеть без смены сигналов EventBus.
- Опасности: шипы, кактус (отбрасывание), пропасть `PitArea` («Висит» у
  левого края по HangPoint секции), движущаяся платформа
  (AnimatableBody2D, детерминирована от run_time, переносит игрока).
- Уровень: `ChunkDef` (метаданные+спавны), `LevelPlan` (чистые данные с
  каноническим хешем), `LevelPlanner` (только RandomNumberGenerator c seed:
  перемешивание Fisher–Yates, каждая 3-я секция — кооп, без повторов и
  соседних дублей), `LevelBuilder` + `chunk.gd`; 6 секций: старт, лёгкая
  (2 пропасти + кактусы + птицы), средняя (шипы + зверёк на платформе +
  движущаяся платформа через пропасть 192 px), кооп (уступ 160 px —
  обычным прыжком не забраться, проход по «опущенной лестнице»), бонусная
  (волна из 12 монет), финиш. Чекпоинт в начале каждой игровой секции,
  стены по краям уровня, градиентное небо.
- Сцена забега `scenes/run.gd`: seed (`--dev-seed` или случайный, пишется
  в лог), сборка, отсчёт 3-2-1-GO, часы run_time, лимит 10 минут («Время
  вышло»), финиш (+5 монет, оверлей с «Ещё раз» / «В меню»), HUD
  (`ui/run_hud.gd`): монеты, «секция X / 6», таймер последние 2 минуты,
  панель «Висит». Меню: «Играть» → одиночный забег; остальные кнопки —
  disabled-заглушки. Бинды раздела 4 в project.godot (physical_keycode —
  раскладконезависимые). Все строки UI — через tr() и strings.csv (ru/en).

**Как проверить на сервере (headless):**
- `godot --headless -s addons/gut/gut_cmdln.gd` — 29 тестов, ~4800
  проверок, все зелёные. В том числе обязательный по разделу 16: детерминизм
  генератора — 1000 seed, два прогона, побитовое сравнение планов.
- `godot --headless scenes/run.tscn --quit-after 500 -- --dev-seed=42` —
  уровень собирается без ошибок; в логе порядок секций.
- Два запуска с `--dev-seed=42` дают одинаковый порядок секций; `--dev-seed=7`
  — другой (кооп всегда 3-я секция).

**Как проверить вручную (ПК с Windows):**
- Открыть проект в Godot 4.7.2 → запустить: Boot → меню → «Играть» → забег.
- Пройти уровень от старта до финиша: перепрыгнуть пропасти 128 px, шипы и
  кактусы (отбрасывают, мигание), переправиться на движущейся платформе,
  забраться по «лестнице» на уступ 160 px, собрать монеты и убить птицу/
  зверька (J или ЛКМ; +1 монета). На финише — «Забег пройден!» и монеты.
- Упасть в пропасть: панель «Висит» с таймером 8 с; «Сдаться» (или таймаут)
  возвращает на чекпоинт начала секции.
- Отпустить прыжок рано/поздно — высота меняется; сойти с края и прыгнуть
  в течение ~0.1 с — coyote time работает.
- Проверить FPS 60 (критерий этапа) и переключение языка ru/en.
- «Ещё раз» — новый забег (новый случайный seed), «В меню» — главное меню.

**Отложено:**
- Сеть ENet, снапшоты, боты (этап 2); плиты, ворота, вытягивание из
  пропасти другим игроком, золотая цель, эмоции, падающие платформы,
  полный пул 14 секций (этап 3).
- Звук: нет ассетов; шины аудио и ducking — с ассетами (раздел 14).
- TileMapLayer-секции: пока геометрия из примитивов (разрешено разделом 14
  для плейсхолдеров), тайлсет — с появлением ассетов.
- Пауза Esc, список игроков Tab, тема UI, шрифт с кириллицей (этап 7);
  сохранение монет в save.json (этап 7).

**Известные проблемы:**
- Отсчёт старта 3 с (по протоколу раздела 8), а не 5 с из раздела 5 —
  для одиночного забега достаточно; при сетевом старте оставить 3 с.
- При пуле из 4 секций вариативность — 6 перестановок; расширится с
  пулом 14 секций на этапе 3.
- Высота прыжка фактически 96.57 px (SPEC округляет до «около 96»).
- Кооп-секция проходится в одиночку по заранее опущенной «лестнице» —
  настоящий кооп-гейт (плиты, ворота, лестница по событию) — этап 3.
