# Чек-лист плейтеста (v2, открытый мир)

Минимум 2 человека на разных ПК с разными Steam-аккаунтами, друзья в Steam.

## Вход
- [ ] «Мир для друзей» → «Пригласить» → друг заходит
- [ ] Друг заходит по приглашению при закрытой игре (+connect_lobby)
- [ ] «В мир» находит мир с людьми или создаёт свой
- [ ] Второй игрок выходит и заходит снова — видит то же состояние мира
- [ ] Rich Presence показывает «На острове (N / 12)»

## Движение и мир
- [ ] Бег, прыжок, камера мышью, приближение колесом
- [ ] На уступ 1.2 м запрыгивается, на 2 м — нет
- [ ] Все 6 зон достижимы, карта (M) показывает себя и друга
- [ ] Цикл дня одинаковый у обоих

## Механики (вдвоём)
- [ ] Вытянуть из расщелины
- [ ] Ворота руин на плитах, сундук даёт монеты обоим
- [ ] Подсадка на уступ в холмах, лестница для второго
- [ ] Золотой светлячок двумя ударами
- [ ] Маяк зажигается вдвоём; после 5 маяков — Звездопад
- [ ] «За руку»: ведомый идёт за ведущим, связь рвётся при отрыве
- [ ] Сесть у костра вместе
- [ ] Колесо эмоций и «Сюда!» видны другому

## Механики (в одиночку, запасные пути)
- [ ] Маяк удержанием 8 с, ворота через 60 с, обходная тропа к уступу

## Голос
- [ ] PTT, иконка динамика, звук идёт из точки говорящего
- [ ] Затухание к 50 м, у костра слышно полностью
- [ ] Мут работает

## Встречи и безопасность
- [ ] «Встречи» показывают друг друга с правильной фразой
- [ ] Подсказка-знакомство всплывает
- [ ] Блок: не слышно, полупрозрачный, нельзя взять за руку
- [ ] «Вернуться на площадь» мгновенно переносит к костру

## Сбои
- [ ] Выход гостя не ломает мир
- [ ] Выход хоста: у всех сообщение и экран «Встречи»
