# Чек-лист плейтеста

Проходится вручную перед каждым плейтестом. Минимум 3 человека на разных ПК с разными Steam-аккаунтами.

## Подключение
- [ ] «Играть» находит лобби с другими игроками за 30 с
- [ ] Одиночные лобби сливаются, если игроки нажали «Играть» почти одновременно
- [ ] «С друзьями» → «Пригласить» → друг входит из запущенной игры
- [ ] Друг входит по приглашению, когда игра у него была закрыта (+connect_lobby)
- [ ] Rich Presence показывает статус в списке друзей Steam

## Лобби и старт
- [ ] В лобби можно бегать, говорить, слать эмоции
- [ ] Отсчёт стартует при минимуме игроков и сокращается при заполнении
- [ ] Все одновременно видят отсчёт 3-2-1 и стартуют вместе

## Геймплей
- [ ] Движения других игроков плавные
- [ ] Монета, которую тянутся взять двое, достаётся одному
- [ ] Убитый моб исчезает у всех
- [ ] Упавший игрок висит 8 с, другой игрок вытягивает его
- [ ] Без помощи упавший возвращается на чекпоинт
- [ ] Кооп-ворота открываются при нужном числе игроков на плитах
- [ ] Кооп-ворота открываются сами через 45 с, если людей мало
- [ ] «Ступенька»: прыжок с головы достаёт до уступа, лестница опускается
- [ ] Золотая цель погибает только от ударов двух разных игроков
- [ ] Колесо эмоций и «Сюда!» видны остальным

## Голос
- [ ] PTT работает, иконка динамика над говорящим
- [ ] Рядом — громко, на расстоянии ~1000 px — тише, дальше 1280 px — не слышно
- [ ] В лобби, на финише и на результатах слышно всех
- [ ] Мут конкретного игрока работает
- [ ] Проверка микрофона в настройках работает

## Результаты
- [ ] В топе те, с кем реально взаимодействовал
- [ ] Фразы-моменты соответствуют тому, что было

- [ ] Симпатии доходят до получателя
- [ ] «Ещё раз с этой компанией» переносит проголосовавших в новое лобби
- [ ] В user://logs/runs.jsonl появилась запись

## Безопасность
- [ ] Заблокированный не слышен и полупрозрачен
- [ ] Быстрая игра не приводит в лобби с заблокированным
- [ ] Жалоба приходит на webhook (или в лог, если URL не задан)
- [ ] Разблокировка в настройках работает

## Сбои

- [ ] Выход хоста посреди забега: у всех сообщение и экран результатов
