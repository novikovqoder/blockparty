1. Распакуй без перезаписи:
   `cd ~/blockparty && git checkout born-unblessed && git pull && unzip -n ~/born_unblessed_gfx_high_opt_kit.zip`

   и SSIL дешевле, без MSAA — только SMAA, тени 4096 Soft Medium, туман 128×64, пробы
   срубов, трава и параллакс экономнее. ULTRA не менять. Новая настройка «Разрешение 3D»
