## П5.9 — Главное меню Born Unblessed

**Цель.** Заменить главное меню на новое — тёмное средневековье, рабочее
название игры Born Unblessed. Готовый комплект сцены лежит в репозитории
(`scenes/menu_bu/`, `ui/theme_bu/`, `assets/menu_bu/`, `i18n/strings_bu.csv`,
`tests/test_main_menu_bu.gd`, `tools/capture_menu_bu.gd`, описание —
`docs/menu_bu/README.md`). Задача этапа — встроить его, а не писать заново.

**Что должно получиться.**
1. После загрузки (и после окна «Steam не запущен» → «Играть офлайн»)
   открывается `scenes/menu_bu/main_menu_bu.tscn`.
2. Пункты: Продолжить, Новая игра, Главы, Настройки, Авторы, Выход.
   Фон — широкая панорама собора. Камера поворачивает к своему кадру для
   каждого раздела: Настройки — вправо (клетка, пролом в крыше), Авторы —
   влево (угол со скелетами), Главы — к полу. Продолжить/Новая игра — наезд на рыцаря
   и затухание.
3. Сигнал `start_requested(mode)` временно ведёт туда же, куда сейчас ведёт
   «В мир» (одиночный мир), чтобы сборка оставалась играбельной. Сюжетной
   игры пока нет.
4. Старое меню Blockparty доступно по dev-аргументу `--old-menu`
   (вход в «Мир для друзей», редактор внешности и т. п. не теряется).
5. Строки `i18n/strings_bu.csv` подключены к переводам проекта (ru/en).
6. Настройки меню сохраняются в `user://settings_bu.cfg` и применяются при
   запуске; громкость — через шины Master/Music/SFX/Ambient/Voice
   (недостающие шины создать в `default_bus_layout.tres`).
7. Код комплекта не переписывать без необходимости. Допустимы правки для
   интеграции и под правила `CLAUDE.md`; правки перечислить в STATUS.md.

**Исключения из правила «только CC0» (решение владельца).**
- `assets/menu_bu/*` — иллюстрации владельца, сделанные с помощью ИИ.
- `ui/theme_bu/fonts/*` — шрифты Cormorant и Manrope, SIL OFL 1.1.
Оба пункта внести в `assets/third_party/LICENSES.md` с пометкой «исключение».

**Приёмка.**
- Тесты GUT зелёные, включая `tests/test_main_menu_bu.gd`.
- Скриншоты всех разделов: `tools/capture_menu_bu.gd` →
  `docs/screenshots/P5.9/` (на сервере через `xvfb-run -a`).
- Ручная проверка владельцем в сборке для Windows: переходы, звук
  молнии/музыки (если подключены), затухание при старте, Esc, геймпад.

**Не входит в этап.** Сюжетная игра, система сохранений и глав, переназначение
клавиш, музыка меню (слот `music_stream` пустой).
