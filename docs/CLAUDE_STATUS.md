# Статус работы Claude (ветка bu-claude)

СТАТУС: В РАБОТЕ

Задача: перенести картинку из демо-мира (деревья EZ-Tree без елей, трава и цветы
как в демо ezTree, земля, вода озера, свет) в игру; управление — шаг по умолчанию,
Shift — бег, боевая стойка только с выхваченным мечом. Цель производительности —
не меньше 30 FPS на Radeon 780M на «Высоком».

Когда работа будет закончена, первая строка станет «СТАТУС: ГОТОВО К СБОРКЕ»,
ниже — что сделано и что проверить.
