# Лицензии и титры: assets_inbox/postapoc/

Ассеты для новой игры (постапокалипсис, реализм), отобранные из локальной библиотеки
`~/blockparty/library/` (разведка П12). Всего 161 набор, суммарно ~495 МБ.

- **Все выложенные наборы — CC0 1.0 (public domain).** Атрибуция не требуется,
  но авторы и страницы источников перечислены ниже для прозрачности.
- Файлы лицензий внутри самих наборов ambientCG / Poly Haven отсутствуют
  (эти сайты не кладут лицензию в архивы) — лицензия каждого набора взята из
  `library/catalog.csv` (заполнен при скачивании) и соответствует официальной
  политике сайтов: ambientCG и Poly Haven публикуют эти материалы под CC0.
- Что вырезано из архивов при выкладке (для укладки в лимит 500 МБ):
  - `ambientcg`: оставлены только карты `*_1K-JPG_Color/_Displacement/_NormalGL.jpg`
    и превью `.png`; варианты 2K, `NormalDX`, `.blend`, `.usdc`, `.mtlx`, `.tres` не копировались.
  - `polyhaven/textures` и `polyhaven/models`: оставлены `*_1k` карты
    (ao / arm / diffuse / displacement / nor_gl) и `preview.jpg`;
    варианты `*_2k`, `nor_dx`, `rough`, `rough_ao` удалены.
  - Геометрия моделей (`.gltf` + `.bin`) скопирована без изменений.
