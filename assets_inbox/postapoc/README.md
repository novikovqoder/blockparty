# assets_inbox/postapoc/ — ассеты для постапокалипсиса

Отбор из локальной библиотеки `~/blockparty/library/` (ambientCG, Poly Haven).
Стиль — реализм, лицензия всех наборов — CC0. Титры: `LICENSES.md` в этой папке.
Полный аудит (включая то, что НЕ выложено, и пробелы по категориям):
`docs/ASSETS_POSTAPOC.md` на ветке `postapoc-assets`.

## Структура

```
ambientcg/<Категория>/<ID>/   — PBR-текстуры 1K (Color / Displacement / NormalGL + превью)
polyhaven/textures/<имя>/     — PBR-текстуры 1k (ao / arm / diffuse / displacement / nor_gl + preview)
polyhaven/models/<Имя>/       — фотоскан-модели (.gltf + .bin + textures 1k + preview)
```

## Состав (161 набор, ~495 МБ)

- **Текстуры** (~92): бетон и панели, кирпич, облупленная краска/штукатурка,
  ржавчина, асфальт (в т. ч. повреждённый), грязь/грунт, мох и зарастание,
  обои, линолеум, граффити, потёки, тротуарная плитка, двери, фасады.
- **Модели** (~73): фасад многоквартирного дома (модульный), пожарная лестница,
  рольставни (окна/дверь), забор-сетка, столбы ЛЭП с проводами, водостоки,
  урна, мешок мусора, покрышка, ржавые диски, бетонный блок, фонарь, гидрант,
  скамейка, машина под тентом, бочки, канистры, ящики, бутылки, ржавая банка,
  огнетушитель, камеры наблюдения, кондиционер, телефон-автомат, противогаз,
  люк, крыса; мебель (кровать с рамой, плита, печь, микроволновка, телевизоры,
  шкаф/стеллажи, диваны, стулья, столы, кресло-каталка, вентилятор); мох,
  сорняки (крапива, одуванчик, трава), сухое дерево, кусты, корни.

## Замечания

- Оригиналы (2K/4K, .blend и пр.) остались в `~/blockparty/library/` — при
  необходимости можно докачать точечно из выкладки в library.
- Godot 4.7 импортирует `.gltf` + `.bin` + jpg напрямую; карты `nor_gl`
  уже в правильной (OpenGL) конвенции.
